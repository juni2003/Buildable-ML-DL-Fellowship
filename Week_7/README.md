# Week 7: Airbnb Listing Analysis (Albany, NY)

This folder contains all code, notebooks, figures, and reports for the Week 7 assignment of the Buildable ML/DL Fellowship Program.

## Assignment Overview

- **Data Cleaning & Exploration:** Load and clean the Albany, NY Airbnb dataset.
- **Feature Engineering:** Create new features using text, geospatial, and categorical data.
- **Regression & Classification:** Build models to predict price and popularity.
- **Deep Learning Experiment:** Use a neural network to predict price.
- **GitHub Workflow:** Use multiple branches and pull requests to organize your work.

All files related to this assignment should be kept in this folder.
